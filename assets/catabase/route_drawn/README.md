# Signes de la descente

Douze pictogrammes dessinés pour Catabase d'Achille, inspirés de son monde grec :
traits d'encre légèrement irréguliers, formes ouvertes et aucun relief.
SVG 64 × 64, teintés par la carte ; la légende et la fiche utilisent les mêmes sources.

| Destination | Signe |
| --- | --- |
| Combat | Aspis et lance verticale |
| Élite | Casque à nasal et crête |
| Boss | Arc tendu de Pâris |
| Refuge | Rameau d'olivier sur une pierre |
| Marchand | Balance à deux plateaux |
| Sanctuaire | Autel à degrés et offrande végétale |
| Mémoire | Stèle gravée, bord ébréché |
| Rencontre | Deux profils face à face |
| Cache | Amphore à deux anses |
| Inconnu | Spirale du Léthé, écho non déchiffré |
| Passage découvert | Trace entre deux racines |
| Position | Empreinte de sandale |

Les cercles dessinés par l'interface signalent un état de navigation.
Ils ne font pas partie des pictogrammes.
