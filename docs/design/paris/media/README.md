# Captures historiques de Paris — lot v1

Ces fichiers ont été produits avant l'ajout, le 7 septembre 2026, du soin complet à la métamorphose :

- `paris_final_room_v1.png` : salle finale réelle, déploiement initial.
- `paris_transform_v1.gif` et `paris_transform_v1.poster.png` : transformation et attaques dans le duel de validation initial.
- `paris_transform_v1.encode_report.json` : reçu d'encodage des pixels et timestamps de cet extrait.

Ils restent des preuves de la version enregistrée, dans laquelle Paris ne récupérait pas ses PV en devenant démon. Ils ne prouvent pas le soin de la règle actuelle. Aucun pixel, timestamp ou montant des rapports n'est réécrit.

Le rapport associé `../../paris_combat_validation_v1.json` conserve les mêmes faits historiques. Les règles actuelles sont décrites dans `../../paris_gameplay_v1.md`.
