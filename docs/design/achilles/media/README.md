# Captures du combat réel

- achilles_classic_walk_bow_S.gif : marche sur trois cases, tir simple, retour au repos ; derniers sprites S et contours corrigés.
- achilles_lightning_E.gif : marche puis sort de foudre appris et équipé par le catalogue réel d’expédition.

Les GIF proviennent des captures horodatées du moteur, avec cadrage fixe agrandi deux fois. Aucun temps de pose supplémentaire n’est ajouté. Les images identiques peuvent être fusionnées avec leur durée ; les rapports .encode.json vérifient ordre, transitions et durée totale. Le coût de capture GPU est distinct des mesures sans capture. Voir le reçu de livraison parent pour les tests et limites.
