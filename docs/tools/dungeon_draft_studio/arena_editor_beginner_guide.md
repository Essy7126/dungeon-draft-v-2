# Arena Studio 2.0 — guide débutant

Statut : **WORKTREE_CANDIDATE**.

1. Ouvrez la visite guidée et choisissez une run, une salle et un héros par leur nom.
2. Démarrez l’exercice sandbox depuis **Productions et récupérations**. Tout est créé sous `user://dungeon_draft_studio/tests/`.
3. Travaillez dans la copie de travail : choisissez PAINTED, MODULAR ou HYBRID, ajoutez les cases, peignez les terrains, placez murs et spawns.
4. Vérifiez Logique, Art, puis Jeu. Le badge Rapide/Exact indique la fidélité réelle.
5. Validez, corrigez les erreurs cliquables, puis utilisez Tester. Tester charge une copie temporaire dans la vraie scène sans sauver la salle officielle.
6. Exportez le kit artistique, livrez un décor à la résolution exacte, réimportez et confirmez l’overlay.
7. Dans Production, lisez d’abord « Vous allez ». UPDATE conserve rencontre, vagues et récompenses ; REPLACE remplace toute la salle.
8. En cas de bundle incomplet, consultez son état. Archiver/reconstruire reste explicite et un bundle référencé est bloqué.
9. Intégrez dans la run fixture, puis utilisez le rollback de l’exercice. Fermez/rechargez pour vérifier.

Les chemins et hashes sont cachés sous **Détails techniques**. Détacher puis **Réintégrer la fenêtre** conserve la même working copy.
