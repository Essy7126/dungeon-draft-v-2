# ArenaDefinition — schéma v2 (historique)

Ce document ne décrit plus le schéma courant. La v2 a introduit les modes
PAINTED/MODULAR/HYBRID, les profils visuels modulaires, les identités de terrain,
les murs configurés, les objectifs et les décorations.

Le schéma courant et la chaîne de migration complète sont décrits dans
[ArenaDefinition — schéma v3](arena_definition_schema_v3.md).
