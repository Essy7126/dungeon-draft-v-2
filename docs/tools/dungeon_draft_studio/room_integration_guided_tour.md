# Guide de la visite Arena Studio

La visite intégrée est disponible depuis **? Visite guidée** dans la barre
supérieure ou depuis **Visite guidée** dans le panneau Destination.

Elle comporte quatorze étapes :

1. bienvenue et copie de travail non destructive ;
2. run ;
3. salle ;
4. arène ;
5. grille tactique et calibration ;
6. création des dalles ;
7. murs, obstacles et spawns ;
8. export de la référence artistique ;
9. réimport du décor ;
10. vues Logique, Art et Jeu ;
11. validation ;
12. test runtime ;
13. choix de la destination ;
14. intégration, recovery, reload et sélection finale.

**Précédent**, **Suivant**, **Recommencer** et **Terminer** permettent de la
parcourir sans modifier le document. Le bouton placé dans Destination ouvre
directement l’étape correspondante.

Le vocabulaire de la visite suit le contrat du Studio : une arène met à jour la
partie tactique et visuelle d’une salle ; le gameplay de cette salle reste
conservé avec l’action recommandée. « Réintégrer » désigne toujours la fenêtre,
jamais une salle.
