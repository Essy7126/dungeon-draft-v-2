# Guide utilisateur — transformer une grille

1. Ouvrez Dungeon Draft Studio, onglet **Arènes**, puis choisissez Forêt,
   Volcan, Espace ou une ArenaDefinition.
2. Choisissez **Transformer la grille**, puis cliquez la grille. Le gizmo
   apparaît.
3. Glissez l'intérieur pour déplacer toute la grille.
4. Glissez la poignée droite ou gauche pour modifier l'inclinaison
   correspondante.
5. Glissez la poignée de rotation pour tourner la grille ; glissez la poignée
   d'échelle pour l'agrandir ou la réduire uniformément.
6. Glissez le pivot pour choisir un centre personnalisé.
7. Maintenez **Shift dès l'appui** pour un réglage fin. Maintenez **Ctrl dès
   l'appui** pour inverser temporairement l'aimantation. Les flèches déplacent
   d'un pixel, Shift+flèche d'un pas fin et Ctrl+flèche de dix pixels.
8. Appuyez sur **Échap** ou faites un clic droit pour annuler le geste courant.
9. Utilisez les boutons Annuler/Rétablir ou Ctrl+Z, Ctrl+Shift+Z et Ctrl+Y pour
   parcourir plusieurs opérations.
10. Ouvrez **Historique** pour voir les actions, la position courante et la
    version sauvegardée, puis cliquez un état pour y revenir.
11. Passez à **Ancres de calibration**, placez au moins trois ancres réparties,
    puis lancez l'ajustement automatique. Vérifiez RMS, erreur maximale et
    résidus.
12. Activez la comparaison sauvegardée/actuelle pour superposer la référence.
13. Dans Points de restauration, créez un point nommé avant une modification
    risquée. Il peut ensuite être renommé, restauré ou supprimé.
14. Cliquez **Tester** pour lancer une copie temporaire de la working copy dans
    le vrai parcours de combat.
15. Cliquez **Sauvegarder** seulement après validation. La source sur disque
    reste inchangée jusque-là.

Le mode Avancé expose O/U/V numériquement. Il n'est pas requis pour le parcours
normal et ses champs valident une modification logique, pas chaque frappe.
