# Achilles HUD frame kit v1

Vector presentation assets for the production Achilles HUD. The kit is built
around the 1672×941 reference composition: a 1444×140 three-module chassis,
with independent portrait, action, spell and health frames.

The SVGs contain no gameplay text or state meaning. Interaction state remains
implemented by the HUD components so hover, focus, selection, cooldown and
disabled feedback stay accessible and testable.
