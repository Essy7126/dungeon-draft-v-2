# Matières des interfaces joueur

Créations vectorielles originales : brun d’ombre, liseré bronze fin, fibres discrètes.
Découpe à neuf zones de 24 px ; aucun motif sous les textes à contraste élevé.
`umber_panel.svg` : panneaux du dossier et fiches de survol.
`umber_card.svg` : fond des cartes, à transparence réduite pour conserver les états de sélection.
Les bordures de rareté et les labels restent indépendants de la matière.
